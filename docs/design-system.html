A single visual language blending majd-portfolio's minimal, motion-led calm with jora.uz's local, professional warmth. Dark-first, blue-accented, trilingual — built to lead with services, then prove with work.

Dark-first, one blue voice

07 — Motion

Restrained, like majd

Motion confirms structure, it doesn't perform. One reveal pattern, one hover pattern, everything eased the same way. Reduced-motion users get a still, complete page.
